# Scratch Offline
Scratch Offline is a tool that allows Scratch to run on apple devices offline.
⚠️ WARNING: Any extensions that requires Wi-Fi will not work unless internet is turned on.

# Here's how to install Scratch on your apple device:
1. Open Safari and go to the website (wizwazwuz.github.io/scratch-offline)
2. Safari will start to download the website to your device. 
3. After the editor loads, Scratch should be downloaded.
4. In the top right corner, press the share button, click "View More" at the bottom of the menu and scroll till you see "Add to Home Screen."
5. Click it and just name Scratch whatever you want. A new app should add to your home screen.
6. To see if this works, turn off Wi-Fi or turn on airplane mode, and press the new app. If it loads, CONGRATS! 🎉




# FYI: The current offline version doesn't support face sensing or any new blocks. We will focus on adding that in the future.
